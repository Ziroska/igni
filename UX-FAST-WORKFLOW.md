# IGNI Manager — UX Fast Workflow

Ветка: `ux-fast-workflow`

## Цель
Сократить количество действий кальянного мастера в зале без изменения текущей схемы Room и без риска для сохранённых данных.

## Первый пакет
- Свободный стол: обычный тап сразу открывает создание кальяна.
- Занятый стол: обычный тап сразу открывает рабочую боковую панель.
- Замена углей: одно действие из рабочей панели.
- Повтор текущего кальяна: отдельное быстрое действие с автоматическим списанием со склада.
- После создания кальяна стол должен оставаться выбранным и сразу показывать активную панель.
- Долгое нажатие используется только для вторичных быстрых действий.

## Второй пакет
- Выбор постоянного гостя из CRM автоматически подставляет его обычную крепость и чашу.
- Быстрый повтор последнего кальяна гостя из CRM.
- Сокращённая форма открытия стола для постоянного гостя.

## Правила
- `main` не изменяется до проверки сборки и ручного теста UX.
- Не менять схему Room в первом пакете.
- Не ломать совместимость с существующими ActiveTableSessionEntity и CRM-историей.
